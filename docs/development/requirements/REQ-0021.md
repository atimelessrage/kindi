# REQ-0021: CPU + Intel integrated-graphics tandem (SYCL/Level Zero)

- Status: proposed

## Requirement

Kindi runs a CPU + Intel integrated-graphics tandem layer split on the
many CPUs that ship an 11th-generation-or-newer UHD, Iris Xe, or
built-in Arc iGPU: one model whose layers are split between the CPU
engine and the iGPU over shared system memory, token-exact, through
Kindi's own engine. The investigation, stack decision and gates are
`docs/INTEL-IGPU-TANDEM.md`. This requirement sits beside REQ-0020
(Arc A770): the iGPU route is a retarget of that SYCL backend, not a
second backend.

## Acceptance

- G0 (qualification): an 11th-gen+ / Iris Xe / built-in-Arc iGPU
  visible in Level Zero, shared-memory limit recorded, pinned
  compute-runtime version.
- G1 (single device): 2B plain SYCL path, `kindi verify` 4/4
  token-exact.
- G2 (tandem): CPU+iGPU layer split token-exact 4/4 and decode
  ≥1.15x the CPU-only engine on the same host; otherwise the tandem
  is a documented no-go, like the NVIDIA tandem.
- G3: 4B/9B within the shared budget (half of RAM, or the Core Ultra
  2+ override), 8K behaviour measured.
- The fit model uses the shared-memory budget; `kindi/info` reports
  the shared limit, not a VRAM number.

## Evidence

- Investigation only (2026-11-15). External evidence: llama.cpp SYCL
  verifies iGPUs in 11th–13th gen Core and built-in Arc; Panther Lake
  Vulkan/SYCL decode 1.6–1.7x CPU on a small model; older Iris Xe
  decode can lose to a many-core CPU, which is why G2 is a gate.
- No Kindi iGPU measurement exists. The test host's i7-8086K (UHD 630,
  Gen9) is below Intel's oneAPI floor (11th gen / Iris Xe or newer)
  and shows no Intel device, so G0 needs other hardware (built-in
  Arc first). `docs/SUPPORT-MATRIX.md` renders the iGPU rows as
  `not measured`; the installer must not offer Intel graphics as
  supported until G3 passes.
