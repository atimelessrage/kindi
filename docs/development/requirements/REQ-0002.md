# REQ-0002: Bonsai packs convert losslessly

- Status: active

## Requirement

Kindi must convert supported Bonsai GGUF files into packs without changing tensor values,
scales, tokenizer behavior or the model's arithmetic. Conversion must reject a source
layout it cannot represent exactly.

## Acceptance

- Conversion accepts the documented GGUF formats, including the PQ2_0 and Q2_0 variants,
  and records the source format in the pack manifest.
- The tokenizer and vocabulary round-trip matches llama.cpp on chat, code, tool-call and
  Unicode inputs.
- Pack conversion is deterministic for the same source and conversion settings.
- Unsupported block layouts, grouped dimensions or scales are refused with an actionable
  error instead of silently approximated.

## Evidence

- `kindi/convert.py` and `kindi/layout.py` implement conversion and rejection rules.
- `tests/test_convert.py` and `tests/test_tokenizer.py` cover conversion and tokenization.
- [`BONSAI-2-SUPPORT.md`](../../BONSAI-2-SUPPORT.md) and
  [`SUPPORT-MATRIX.md`](../../SUPPORT-MATRIX.md) record supported formats and models.
