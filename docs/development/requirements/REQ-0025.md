# REQ-0025: `kindi verify` can run under speculation

- Status: proposed

## Requirement

Every speculation mode must be token-compared against the reference exactly like the plain engine.
`docs/MTP.md` states that "the output of every mode was the same as without speculation"; no gate
checks it, and `kindi verify` cannot: `spec_mode` is only ever set by the server's engine build, so
the engine `verify` constructs has speculation off.

`kindi verify` must accept a speculation mode (`KINDI_SPEC=ngram|draft2b|dspine|mtp|both` and the
mode's own variables) and report the mode it ran, with the same 4/4-style exactness verdict.

## Acceptance

- **A1 (open): the mode is selected by the harness, and reported.** `kindi verify` prints the
  effective mode and its drafter/head on a first line, so a PASS cannot be read as a plain-engine
  result when speculation was off, and vice versa.
- **A2 (open): mode A is exact, or the documentation changes.** With `KINDI_SPEC=mtp` and the
  registered 2B head on the RTX 4060 Ti, `kindi verify` is token-exact against the pinned reference
  at the verify length, or `docs/MTP.md`'s "same output" sentence is corrected to what was measured.
- **A3 (open): every shippable mode has a cell.** `ngram`, `draft2b` and `both` on the 2B;
  `dspine` needs its weights, so it lands as an owner-action row when they are not here.
- **A4 (open): a refusal is named.** A mode whose drafter cannot load exits non-zero with the
  reason, instead of quietly verifying the plain engine (the exact failure REQ-0024 A1 addresses).
- **A5 (standing): the plain path is unchanged.** `kindi verify` with no `KINDI_SPEC` keeps its
  current output, and `tools/verify_matrix.py` keeps its modes.

## Evidence

- Existing: `kindi/spec.py:1277` (`self.spec_mode = mode`, set by the server build only);
  `tools/verify_matrix.py` (mode matrix without a speculation mode); `docs/MTP.md` "Measured speed"
  ("The output of every mode was the same as without speculation").
- The gap in this round: mode A was measured for tok/s (0.66x) but never for exactness — the head
  was fixed and benchmarked, and the token-for-token check was not available.
- Related: `CURRENT-VS-KINDI-0.6.md` §41, `docs/MTP.md` "Measured 2026-11-17", `d1d23f2`.
