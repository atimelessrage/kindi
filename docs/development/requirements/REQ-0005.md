# REQ-0005: The serving boundary is predictable and bounded

- Status: active

## Requirement

The server must expose the documented OpenAI-compatible API and the supported Ollama
compatibility endpoints, serialize inference, bound waiting clients, and report queue and
request metrics without leaking the API key.

## Acceptance

- Invalid requests, oversized bodies and image inputs on text-only packs fail with a
  structured HTTP error instead of reaching the engine.
- At most `KINDI_QUEUE_MAX` requests wait; additional requests receive HTTP 429 with
  `Retry-After`.
- `/health`, `/metrics`, `/api/tags`, `/api/chat` and `/api/generate` behave as documented,
  and the API key protects them when configured.
- Streaming responses terminate correctly and do not leave the queue state inconsistent.

## Evidence

- `kindi/server.py`, `tests/test_server.py`, `tests/test_requirement_coverage.py` and
  `docs/AGENTS.md` define and test the contract.
- The 9B CPU queue load check in [`AGENTS.md`](../../AGENTS.md) exercised 12 clients with
  nine HTTP 200 responses and three bounded HTTP 429 responses.
