# REQ-0011: Credentials and personal data stay out of the repository

- Status: active

## Requirement

Tracked files must not contain credentials, private keys, tokens, personal email addresses
or local home-directory paths. The server must protect configured endpoints with its API
key and must not log or return secret values.

## Acceptance

- The tracked-file scan reports no credential or personal-data finding.
- Documentation examples use placeholders, not live keys or absolute user paths.
- When an API key is configured, all protected HTTP routes reject an invalid or missing
  key with a constant-time comparison path.
- A request-body limit and validation failures do not echo request contents or secrets.

## Evidence

- `tests/test_no_secrets.py` scans tracked files without printing matched values.
- `kindi/server.py` and `tests/test_server.py` cover authentication and request limits.
- [`SECURITY.md`](../../../SECURITY.md) is the user-facing reporting and handling policy.
