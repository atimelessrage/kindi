# REQ-0008: The installer classifies cards and edits safely

- Status: active

## Requirement

The installer must classify supported NVIDIA cards by compute capability and memory,
offer only model/context combinations that can fit, pair cards by the documented policy,
and never overwrite unrelated boot or host configuration.

## Acceptance

- Every sm_80-or-newer card is classified as `tc`, regardless of its memory size.
- Two cards pair only when they are the same class and each has enough memory; mixed
  classes and undersized cards are rejected.
- The GRUB edit preserves existing kernel parameters and is covered by a fixture test.
- The installer remains parseable by `bash -n` and keeps the documented source-archive
  checksum behavior.
- An unverified card remains a classification or plan, not a support claim.

## Evidence

- `install.sh`, `tests/test_installer_cards.py` and `tests/test_installer_grub.py` cover
  classification, pairing and the boot edit.
- [`CARD-SUPPORT.md`](../../CARD-SUPPORT.md) records the measured and unmeasured targets.
- [`INSTALL.md`](../../INSTALL.md) is the user-facing installation contract.
