# REQ-0003: Tensor-core plans are exact or explicitly refused

- Status: active

## Requirement

The tensor-core plan engine must use plans and kernels that preserve the verified greedy
result, or refuse an unsupported geometry before graph construction. Narrow geometry
guards must be explicit, tested and logged rather than hidden approximations.

## Acceptance

- The 2B and 27B tensor-core paths pass verification; the 4B path passes with the documented
  split-decode fallback and accepted tie.
- The 9B's 4096-point Hadamard block is refused with an instruction to use the plain
  engine; no partial graph is built.
- A streamed weight cache is used only when its keys cover the current tensor slices.
- The guard and cache decisions are recorded in [`DECISIONS.md`](../DECISIONS.md) and are
  covered by CPU-only tests.

## Evidence

- `kindi/tp.py`, `kindi/spec.py` and `kindi/tc*.cu` implement the plans, guards and cache
  loading.
- `tests/test_plan_engine.py` covers the 4B FD fallback, the 9B refusal and the streamed
  cache-key check.
- [`CARDS.md`](../../CARDS.md) and [`CARD-SUPPORT.md`](../../CARD-SUPPORT.md) record the
  measured card results; the 9B tc path remains unsupported.
