# REQ-0012: K8/V4 is experimental and quarantined

- Status: experimental

## Requirement

The k8v4 K/V mode may remain available for experiments, but it must never be selected by
default, must require an explicit opt-in, and must not be described as token-exact or as a
supported replacement for q8_0.

## Acceptance

- `KINDI_KV=k8v4` refuses to run unless the documented experimental opt-in is set.
- The refusal names the measured loss and the verified fallback.
- The mode is excluded from support claims and from default installer profiles.
- Any future claim of support requires a new exactness run and a recorded decision that
  supersedes the quarantine.

## Evidence

- `kindi/tp.py` contains the opt-in guard; `tests/test_k8v4.py` pins it.
- [`ROADMAP.md`](../../ROADMAP.md) and [`DECISIONS.md`](../DECISIONS.md) record the
  decision and the open verification gap.
- [`SUPPORT-MATRIX.md`](../../SUPPORT-MATRIX.md) marks the mode as experimental.
