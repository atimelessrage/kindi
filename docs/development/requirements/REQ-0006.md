# REQ-0006: Prefix caches are exact and invalidate safely

- Status: active

## Requirement

Cached recurrent state, parked conversations and saved openings must reproduce the same
continuation as a cold run, and a cache produced for an incompatible pack, layout or engine
must never be used.

## Acceptance

- A saved opening can be loaded after a process restart with the expected cached-token
  count and a bit-identical reply.
- The cache fingerprint covers the pack and engine settings that affect arithmetic or
  layout.
- A missing or stale tensor key causes a rebuild or a clear refusal, not a partially
  initialized engine.

## Evidence

- `kindi/cache.py` and `kindi/chunk.py` implement cache selection and state handling.
- `tests/test_cache_decisions.py` and `tests/test_requirement_coverage.py` cover cache
  decisions and saved-opening invalidation; `tests/test_plan_engine.py` covers the
  streamed `g5` key-set guard.
- [`VERIFICATION.md`](../../VERIFICATION.md) records the 27B server/cache cycle.
