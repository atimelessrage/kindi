# REQ-0009: Configuration precedence and references are consistent

- Status: active

## Requirement

Configuration must follow the documented precedence, and the generated configuration
reference must match the actual defaults and environment reads.

## Acceptance

- Built-in defaults are overridden by the config file, then the environment, then
  command-line flags.
- Explicitly configured values are distinguishable from profile defaults.
- Every `config.DEFAULTS` key and `KINDI_*` read appears in the generated reference.
- `python -m kindi.config_reference --check` fails when the reference is stale.

## Evidence

- `kindi/config.py`, `kindi/config_reference.py` and `tests/test_config.py` implement and
  test precedence.
- `tests/test_config_reference.py` checks generated-file drift.
- [`CONFIGURATION.md`](../../CONFIGURATION.md) and
  [`CONFIGURATION-REFERENCE.md`](../../CONFIGURATION-REFERENCE.md) are the user-facing and
  generated references.
