# REQ-0007: Sampling settings are explicit and reproducible

- Status: active

## Requirement

Sampling profiles and per-request penalties must have a documented precedence, use the
publisher's values when selected, and leave greedy output deterministic.

## Acceptance

- A request value overrides a configured value, and a configured value overrides the
  selected profile; the default profile preserves prior behavior.
- `presence_penalty` is applied once per token already present, in the documented range.
- Profiles that need it use the documented non-thinking and thinking values, including the
  output limit.
- Sampling settings that cannot be applied to a backend cause an explicit error, not a
  silent fallback.

## Evidence

- `kindi/sampling.py`, `kindi/profiles.py` and `kindi/config.py` implement the precedence.
- `tests/test_sampling.py`, `tests/test_profiles.py` and `tests/test_config.py` cover the
  behavior; `tests/test_server.py` covers request validation.
- [`CONFIGURATION.md`](../../CONFIGURATION.md) is the user-facing reference.
