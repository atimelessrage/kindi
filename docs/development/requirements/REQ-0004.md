# REQ-0004: CPU inference is exact and ISA-safe

- Status: active

## Requirement

The CPU engine must produce the verified token sequence on supported x86-64 CPUs, check
the instruction set before building, and choose a thread count that does not collapse at
hyperthread barriers.

## Acceptance

- The engine requires AVX2, FMA and F16C and fails with an actionable message when the
  compiler or CPU cannot provide them.
- The native Windows build path works without a vcvars shell when clang and the LLVM
  installation are supplied.
- The 2B, 4B and 9B CPU paths pass verification; the default is one thread per physical
  core, not one per logical CPU.
- The native CPU server answers non-streaming and streaming chat requests with zero GPU
  memory in use.

## Evidence

- `kindi/cpu.py`, `kindi/kcpu.c` and `tests/test_cpu_build.py` implement and guard the
  build; `tests/test_cpu_threads.py` covers topology and defaults.
- [`CPU-SUPPORT.md`](../../CPU-SUPPORT.md) records the verification and thread sweep.
- `tests/test_cpu_smoke.py` and the opt-in CPU exactness test cover a compiled library.
