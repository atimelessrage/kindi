# REQ-0010: Internal and external documentation stay current

- Status: active

## Requirement

Every behavior, support, configuration or workflow change must update the relevant
internal development record and the relevant user-facing documentation or example. Local
links, versions and generated references must remain valid.

## Acceptance

- A behavior change has an updated requirement, architecture note, decision or lesson as
  appropriate.
- `README.md`, `docs/*.md` and `examples/` describe the current behavior and commands.
- Local Markdown links resolve; generated configuration, support and cross-mode files are
  current; image tags and archive names match the package version.
- Requirement history is regenerated after requirement commits and passes `--check`.

## Evidence

- `tests/test_docs_links.py`, `tests/test_config_reference.py`,
  `tests/test_support_matrix.py`, `tests/test_version_consistency.py` and
  `tests/test_project_memory.py` enforce the checks.
- `docs/development/README.md` and `.agents/skills/project-memory/SKILL.md` define the
  workflow.
