## Critical

| # | Finding | Current status |
|---|---------|----------------|
| 1 | FMA3 fallback / Sandy Bridge crash | **Not reproducible as written.** There is no `kcpu_cpuid.c`, `kcpu_cpuid.py` or `kc_set_isa()` in this tree. The live `kindi/kcpu.c` uses AVX2/FMA/F16C unconditionally. Commit `a85cee9` adds a compile-time `#error` naming the missing requirement, so an AVX-only CPU fails clearly instead of with an opaque target error. An AVX-only fallback remains **P1**; the i5-2500K is not supported today. |
| 2 | `rows16_avx512_vnni` incomplete | **Not a live code defect.** No such kernel or VNNI implementation exists in this tree. AVX-512/VNNI/AMX acceleration is an open feature gap, not an incomplete shipped kernel. |
| 3 | CPU ISA dispatch broken | **Not reproducible.** `kcpu_select_isa()` does not exist. The current engine has no runtime ISA dispatch; it is built for the host with `-march=native`. This is a known design limitation, covered by the P1 plan in `docs/CPU-SUPPORT.md`. |
| 4 | Tandem CUDA doorbell kernel missing | **Open feature, not a missing file in a working path.** There is no `kindi/tandem_kernels.cu` and no `TandemEngine`; the tandem work is design-only. See `docs/TANDEM-STATUS.md`. |
| 5 | FP8 support missing | **Open feature.** Kindi has no FP8 model support. The RTX 5060 Ti is classified as `tc`, but its native FP4/FP8 capabilities are not used and no Blackwell speed claim is made. |
| 6 | `kcpu_cpuid.c` referenced but missing | **False for this tree.** Live `kindi/cpu.py` does not import it. The only copies are in the archived WIP backup. |

## Bottom line

The original list overstated the number of live correctness bugs and understated what is already
tested. The integrated branch adds a defensive CPU-build guard, the Blackwell/5060 Ti status
correction and a clean-checkout docs-link test fix; the core engine behavior is unchanged. Tandem, FP8, AVX-512/VNNI/AMX, multi-ISA dispatch, GPU CI,
Windows CI, long-context CI and the AVX-only Sandy Bridge fallback remain open work. They should
be scheduled from `docs/ROADMAP.md` and `docs/CPU-SUPPORT.md`, not treated as regressions fixed
by this report.
